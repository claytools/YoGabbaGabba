# GABBA AFTER DARK

**DJ LANCE IS TRAPPED!**

Find the 5 Gabba characters and their 5 songs to save him.

Every character you find wakes something up.

Get all 10, then make it back to DJ Lance.

## Play

Open the GitHub Pages site on your phone.

- Left thumb: move
- Drag right side: look
- RUN: sprint
- Song buttons: powers

Landscape works best.
